# Vending Machine System

A C++ console-based Vending Machine System that allows administrators to manage inventory and customers to purchase products through a menu-driven interface.

## Features

### Admin Panel

* Create and manage admin accounts
* Secure login with password recovery
* Add, update, and delete products
* Manage product stock and pricing
* View inventory by category
* Track bills and total earnings

### Customer Panel

* Browse products by category
* Search products by name
* Purchase products from selected vendors
* Generate and view receipts

### Additional Features

* File handling for data storage
* Automatic removal of expired products
* Inventory management system
* Billing and receipt generation
* Product categorization

## Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling
* Binary Files
* Standard Template Library (STL)

## Project Structure

* `main.cpp` – Main source code
* `admin.txt` – Admin account records
* `inventory_*.dat` – Inventory data files
* `bills_*.txt` – Billing records

## How to Run

1. Clone the repository.
2. Open the project in your preferred C++ IDE.
3. Compile the source code.
4. Run the executable.
5. Use the menu to access Admin or Customer features.
